# 用电统计发布修订账

保存用电统计从地区报送、审核到公开修订的完整版本与解释。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括地方能源统计单位、国家能源统计人员、行业分析人员、公众数据使用者。

资料所依据的领域事实如下：

- 八月全社会用电量达到一万零三百三十二亿千瓦时
- 报道同时给出分产业当月值与一至八月累计值
- 居民用电下降被解释为台风和强降雨增多导致空调用电减少

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
