# 用电统计发布修订账

保存用电统计从地区报送、自动校验、审核签章到公开发布与修订的完整版本与解释。
月度全社会用电量突破万亿千瓦时后，产业分类调整、地方汇总口径变化、后补计量批次
都会影响同比增速；本服务保证外部使用者能够区分**真实变化**与**统计修订**。

## 角色与职责

| 角色 | 权限 |
| --- | --- |
| 地方能源统计单位（reporter） | 只能维护本辖区的分产业报送、计量批次与气象注记 |
| 国家能源统计人员（analyst） | 复核校验结果并签章，按地区定位不平衡来源 |
| 管理者（administrator） | 批准发布、出具差异说明，举证任一增速的审核轨迹 |
| 公众数据使用者 | 按发布日期复现当时公开的表格（as-of 查询） |

## 模块

- `src/units.js` — 电量单位统一折算为亿千瓦时，拦截单位换算错误。
- `src/classification.js` — 四大产业分项（第一/第二/第三产业、城乡居民生活）；
  行业重分类只能通过带生效月份的显式映射完成，且必须保持各产业合计平衡。
- `src/validation.js` — 自动校验：
  - 分产业合计 = 全社会总量（当月、累计分别勾稽）；
  - 本期累计 = 上期累计 + 当月；
  - 同比增速与上年同期基期算术一致；
  - 后补计量批次不得重复，迟报须登记实际接收时间；
  - 居民生活用电同比下降时必须附气象注记（台风、强降雨等）。
- `src/ledger.js` — 发布修订账：
  - 发布即**冻结**不可变快照（全国表、来源报送、校验结论、签章均整体冻结）；
  - 迟报、单位换算错误、行业重分类、基期修正、勘误五类原因只能产生
    **差异说明 + 新生效版本**，旧版本永不改写；
  - 数据在核准后发生变化必须重新签章；
  - `tableAsOf(period, date)` 复现任意发布日期看到的表格；
  - `auditFigure(period, scope, key)` 给出某个增速/峰值经历的全部版本与审核。

## 契约与示例

- `contracts/submission.schema.json` — 地区报送结构（含批次、行业映射、气象注记）。
- `contracts/release.schema.json` — 冻结发布版本结构（含差异说明与签章）。
- `fixtures/scenario/` — 端到端示例（华东 + 华南，2026 年 8 月）：
  - 初版全国当月全社会用电量 **10320** 亿千瓦时；
  - 华南专线计量点迟报批次 `B-HN-0905` 后补回传，第二产业当月与累计各补计 12；
  - 出具 `late-report` 差异说明后发布第二版，终值 **10332** 亿千瓦时；
  - 两地区均因台风与强降雨登记居民用电下降的气象注记。
